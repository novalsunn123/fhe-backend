# fhe-backend

Development pushes are validated by a self-hosted end-to-end FHE benchmark.
See [`CICD/README.md`](CICD/README.md) for the measured pipeline and report
contents.

Agent-authored source changes are submitted on `agent/*` pull requests. They
are promoted to `dev` only after the candidate improves a primary benchmark or
passes an explicitly allowed speed/memory trade-off against the latest dev
baseline.

## Lịch sử phiên bản dev

Mỗi phiên bản được hệ thống thêm tự động sau khi mã nguồn vượt qua benchmark.
Nội dung gồm thay đổi, cơ chế, cách hoạt động, lợi ích và số liệu so với phiên
bản `dev` ngay trước đó.
